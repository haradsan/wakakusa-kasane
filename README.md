# 若草かさね

彩雲堂の銘菓（若草・伯耆坊・朝汐・あんぱん饅頭・季節のお替わり菓子）をモチーフにした
消込みパズルゲームの試作品です。すべての絵柄はオリジナルのSVGで描かれています。

**▶ 遊ぶ: https://haradsan.github.io/wakakusa-kasane/**

全体の構成（基本システム・季節・情景16枚・カットイン・セリフ・段位・エンディング画像）は
**[構成資料.md](構成資料.md)** にまとめてあります。

## ゲームの目的

**手数が尽きるまでに、どれだけ点を積めるか。** 競うのはこの一点だけです。
最後に出る**段位**は点数だけで決まります。

**詰合せ**は勝敗ではなくボーナスです。一箱詰め終えるごとに**手数と点**がもらえ、
次の箱は一回り大きくなります。急いで詰めるほど長く打てて、点が伸びます。

## 遊びかた（v0.15）

ルールはこれだけです。

- となり同士を入れ替えて、**同じ銘菓を3つ以上となり合わせ**にすると、
  繋がっている分が**まるごと消えます**。たくさん・めずらしい形ほど高得点。
- **一度に5つ以上**消すと**上生菓子（発火剤）**が生まれます。
  となりで消し込みが起きると**小爆発**してまわりを巻き込み、近くの上生菓子にも燃えうつります。
  意匠はそのときの季節の練り切り十二種（春＝桜・梅・菜の花／夏＝紫陽花・朝顔・水の彩／秋＝菊・紅葉・月のうさぎ／冬＝椿・雪うさぎ・花びら餅）。
- 連鎖（一服、二服…）が深いほど点が倍になり、**連鎖の音は季節の歌の一音ずつ**（一服目が一音目、二服目が二音目…「さ・く・ら・さ・く・ら」と六服つなげば「さくらさくら」を奏でたことに）。二十服前後で**完奏**すると、拍手と紙吹雪と「完奏『曲名』」の札でお祝い ― さらに不昧公が**雲州蔵帳の名物**（油屋肩衝・喜左衛門井戸など）を一品披露してくれます（完奏した歌と拝見した名物は結果画面にも並びます）。句の切れ目には太鼓、五服からは小鼓が添います。連鎖のあいだは歌の音階を最優先に、BGMや鳴り物は音程のない太鼓・鼓だけで脇に控えます。曲は季節ごとに一曲（春＝さくらさくら・春が来た・茶摘み／夏＝ほたるこい・たなばたさま・われは海の子／秋＝紅葉・月・虫のこえ／冬＝雪・お正月・一月一日から。いずれも著作権保護期間の満了した曲）。金箔と季節のもの（春の桜吹雪・夏の蛍と金魚・
  秋の紅葉の流れ・冬の風花）が盤を舞って、演出もどんどん**華やか**になります。
  茶碗ゲージが満ちると**不昧公**が降臨し、大茶会の**百花繚乱**。
- **パンダは連鎖の命綱**。ゲージ満タンなら連鎖中にタップして**呼んでおく**と、
  切れ目で自動でつながります。切れ目の「いま！」の合図で叩いても間に合います。
- **茶筅**（1回きり）で盤面をひとまぜ。手詰まりは自動でまぜ直します。
- **五手ごとに、春→夏→秋→冬の順に季節がめぐります**（二十手でひとめぐり。いつ遊んでも春から始まります）。季節が変わると松江の名勝札が画面上部（見出し〜詰合せ窓）に大きく映り、
  背景・舞い散るもの・連鎖の景色が移ろいます。今日の季節の**お替わり銘菓**は仲間入りしたまま。
- **十服（10連鎖）**から松江の情景がカットイン（奇数枚目は季節の情景、偶数枚目は伯耆坊・不昧公の茶室）。
  URLに `?season=spring / summer / autumn / winter` を付けると他の季節から始められます。
- 結果画面は**段階評価**。段位（二級 → 一級 → 初段 …… 五段 → 匠 → 達人 → 名人。名人は10万点の超難関）を**ピラミッドの図**（頂点が名人）で示し、段位ごとの講評と、
  次の段位まであと何点かが出ます。表題は段位に応じて「精進が必要ですな」「結構なお手前で」「お見事！」「感服いたしました」などに変わります。
- 結果画面の末尾は「提供 彩雲堂 ― ご来店をおまちしております。」と、[公式オンラインショップ](https://netshop.saiundo.co.jp/)へのリンクだけの簡潔なものです。
- 右上の **♪** で効果音、**♫** で調べ（BGM）、**投** で投了。

手数は20手スタート。銘菓は**定番5種**（若草・伯耆坊・朝汐・あんぱん饅頭・やまかつら＝薄緑・焦げ茶・グレーの三層）＋**季節枠1種**（春=はな桜／夏=満天／秋=栗まる／冬=柚衣。今日の日付で入れ替わる）の6種類。
